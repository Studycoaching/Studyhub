# Smart Study Hub — CBSE Class 10

A free, responsive static study dashboard inspired by the design reference. It includes the four user-provided Class 10 PDFs, revision starter notes, a quiz practice tool, formula sheets, a local study planner, a progress tracker, and official CBSE/NCERT links.

## Run locally
Open `index.html` in a browser. For the best PDF and GitHub Pages behavior, serve it as a static site (e.g. with GitHub Pages).

## Publish on GitHub Pages (free)
1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, `README.md`, the `papers/` folder, and (when ready) your `himanshu.jpg` portrait to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Wait for the published URL shown in Pages settings.

## Features
- Class 10 only; no login, backend, API key or paid service.
- User-provided PDFs open in a new tab and can be downloaded.
- Official external links open in a new tab.
- Subject/topic revision cards, quiz feedback, formula sheets, a local task planner, dark mode, and progress stats.
- Quiz attempts and planner tasks are stored in the current browser using `localStorage`; they do not sync to other devices and may be removed if browser data is cleared.

## Included PDFs
- `papers/class10-maths-standard-sqp-2026-27.pdf` — Mathematics Standard sample paper 2026–27.
- `papers/class10-maths-question-bank.pdf` — Mathematics question/practice collection supplied by the user.
- `papers/class10-science-sqp-2026-27.pdf` — Science sample paper 2026–27.
- `papers/class10-science-question-bank.pdf` — Science case-study/practice collection supplied by the user.

## Content note
Revision notes and quiz questions are starter learning aids, not a guarantee of full syllabus coverage. Verify coverage against the current official CBSE curriculum and your school. Official CBSE links are provided inside the site. This project is static and has no live AI service.
